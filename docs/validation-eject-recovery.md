# 关闭占用后弹出：验证记录

日期：2026-09-16。目标版本：1.3.0（build 14）。下列实现验收最初在未更改版本号的开发构建上完成，发布构建的验收另记于文末。

## 缺陷复现及修复

- 旧版递归 `lsof +D` 在 Developer 卷的 Spotlight 目录上收到权限错误，导致预检无法进入占用处理；已在原安装应用中复现。
- macOS 的真实 `lsof` 输出带 `f` 文件描述符字段，旧解析器拒绝该字段。新增两项回归测试先在旧代码上失败，再随修复通过。
- 当前查询使用 `lsof -nP +w -F pcLfn +f -- <挂载点>`，不递归遍历目录。异常、超时、权限不足仍作为不完整结果。

## 自动验证

- 完整 `swift test --disable-sandbox`：174 项，3 项按默认设置跳过，0 失败。使用临时 Swift/Clang 缓存路径。
- 额外设置 `DEVDISK_READONLY_TARGET=/Volumes/Developer`：真实拓扑检查与真实文件句柄扫描两项均通过；扫描测试只临时打开并关闭自身的只读目录句柄。
- 涵盖终端工作目录占用、默认未选中任务、选择后 TERM、当前用户系统服务与自身保护、保存等待、释放句柄而未退出、继续检查不重复请求、重新检测保留进度、PID/目标变更、系统拒绝、新占用重新确认、有限重试、取消、权限及未知结果、失败详情保留和中英文资源。
- 最终 `./package.sh -` 通过：Release 编译、ad-hoc 签名验证、菜单栏资源及本地化自检。产物为 `build/DevDisk.app`，不含演示配置。
- `git diff --check` 通过。原有未跟踪 `AGENTS.md` 保留。

## 真实界面检查

使用带独立 bundle ID 的 QA 副本与 DemoMachine；全部占用处理和磁盘弹出为模拟操作。

- 长列表可以滚动，主操作、重新检测和取消固定可见。
- 任务默认未勾选，勾选后显示「关闭占用并弹出」；选择在独立窗口与菜单栏弹层间保持一致。
- 确认后完成模拟流程：8 个应用退出、1 个任务停止，核验模拟物理盘离线后显示可以拔线。
- 保存等待返回「继续检查并弹出」，显示尚未释放的对象，失败详情可展开，复制入口可见。
- 系统拒绝显示阻塞 PID、原始错误及此前已完成的应用退出；刷新后详情保留。
- 切换英文后，缓存的失败说明和相关控件即时显示英文。
- UI 验收后修正成功摘要中的「服务进程」称谓，并在等待诊断中加入已知 PID、翻译步骤名称；随后完整测试与最终打包再次通过。
