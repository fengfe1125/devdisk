## 真实命令验证

1. **现有外置盘只读拓扑检查**：成功识别物理盘、卷与挂载关系；未执行文件扫描、进程停止或弹出。
2. **唯一命名的临时 HFS+ 映像**：创建后仅由受控 `tail` 进程持有测试文件。实际 `lsof` 找到该句柄，普通 `diskutil eject` 在占用时拒绝；受控进程结束后成功弹出，随后核验设备离线。临时资源已清理。
3. **超时与取消**：命令运行器使用自身启动的受控 shell／sleep 子进程验证；弹出结果未知与禁止提示可拔线由模拟系统结果覆盖。

真实输出验证发现 `diskutil info -plist` 在本机不一定包含 `Mounted`，实现据此使用内核挂载表确认挂载状态。生产目标检查继续拒绝磁盘映像和无法确认的复杂拓扑，测试映像不能被误认成可自动清理的外置硬盘。

## 真实界面验收

使用独立 bundle ID 的临时 QA App 副本和显式演示数据。QA 命令运行器不转发任何真实退出、停止或弹出操作。

已观察并操作的状态：

- 深色长预览窗口，展开文件路径证据。
- 浅色短预览，确认后进入成功页面。
- 未知／超时结果页面，仅提供重新检测、取消和普通系统弹出入口。
- 过期预览点击确认后重新检测，未沿用过期确认执行。
- 执行中点击中止，回到结果页面并保留「已中止」及已完成操作计数。
- 系统弹出提交后，明确提示等待结果，中止按钮禁用。
- 真实 NSPopover：长内容处于独立滚动容器，确认、重新检测、取消和版本行位于容器之外并完整可见；与独立窗口共享当前操作状态。

验收菜单打开弹层时需要等菜单跟踪结束，避免菜单关闭连带收起 transient popover。该验收入口只出现在带 `DevDiskDemoScenario` 标记的 QA 副本中，正式 App 不显示。

边界：没有对真实 IDE 的未保存文档发出退出请求；保存／拒绝退出行为由进程替身验证。没有在用户工作盘上执行弹出。当前设备检查不代表所有硬盘盒或文件系统都已完成兼容性验收。
